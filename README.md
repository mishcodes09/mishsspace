A modern, responsive portfolio website showcasing projects, skills, and experience as a Junior Frontend Developer. Built with clean design principles and attention to detail.

🌐 **Live Demo**: [mishsspace.co.za](https://mishsspace.co.za)

## ✨ Features

- **Responsive Design** - Works perfectly on all devices (mobile, tablet, desktop)
- **Modern UI/UX** - Clean, minimalist design with thoughtful interactions
- **Project Showcase** - Display projects with descriptions, tech stack, and links
- **Interactive Timeline** - Visual education and experience timeline
- **Hover Effects** - Smooth animations and hover states throughout
- **Contact Section** - Easy ways to connect (email, LinkedIn, GitHub)
- **Mobile Navigation** - Hamburger menu for mobile devices
- **Performance Optimized** - Fast loading with optimized assets

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with CSS Grid & Flexbox
- **Fonts**: Inter (primary), Instrument Serif (accent)
- **Icons**: Font Awesome, Custom SVG icons
- **Responsive**: Mobile-first approach with media queries
- **Deployment**: GitHub Pages

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic understanding of HTML/CSS/JS (for customization)
